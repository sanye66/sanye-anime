本文档规定产品、工程、测试和交付文档的唯一事实源、同步范围、状态含义、证据要求和自动化检查方式。规则用于减少文档漂移，不替代产品需求、接口契约、数据库设计或安全设计本身。

## 1. 唯一事实源

| 信息类型 | 唯一事实源 | 其他文档的写法 |
| --- | --- | --- |

| 接口路径、方法、字段、错误码 | [api-contract.md](./api-contract.md) | 只引用接口编号和链接 |
| 数据库表、字段、迁移和索引 | [database-design.md](./database-design.md) | 只引用表或迁移编号 |
| 安全、密钥、权限和审计规则 | [security-design.md](./security-design.md) | 只引用安全章节和门禁 |
| 环境变量、供应商和中间件连接 | [environment-config.md](./environment-config.md) | 不在任务、报告和脚本中维护另一套默认值 |
| 指标、告警阈值和监控边界 | [monitoring-design.md](./monitoring-design.md) | 报告引用指标基准 |
| 任务状态、完成定义和实现证据 | [development-tasks.md](./development-tasks.md) | 待办和差距登记引用任务编号 |

## 2. 变更触发矩阵

| 变更类型 | 必须同步的文档 | 必须留下的证据 |
| --- | --- | --- |
| 产品行为、范围、优先级或验收变化 | 产品需求、功能规格、MVP 冻结、决策记录、追溯矩阵、任务清单 | 决策编号、影响范围和验收标准 |
| 接口、字段、错误码或鉴权变化 | API 契约、前后端调用、接口测试报告、相关测试策略 | 请求/响应样例、测试命令和结果 |
| 数据库表、字段或迁移变化 | 数据库设计、迁移清单、任务清单、备份/回滚说明 | 迁移版本、回滚方式和验证结果 |
| 环境、AI 供应商、模型或额度变化 | 环境配置、部署 README、任务证据、性能报告、差距登记 | 非敏感配置、实测状态和外部阻塞 |
| 桌宠窗口、启动关系、交互或视觉边界变化 | 桌宠产品需求、桌宠开发计划、D-026、桌宠待办、桌宠测试报告 | 代码路径、构建命令、截图或兼容性记录 |
| 测试结果、覆盖率或发布门禁变化 | 测试报告、质量门禁、任务完成记录、发布就绪报告 | 命令、通过数、失败数和环境 |

## 3. 文档状态和证据

正式文档头部必须包含文档版本、状态、关联文档和更新时间。状态只使用以下值：

- `草案`：首次编写，尚未评审。
- `评审中`：已提交评审，仍可能调整。
- `基线`：已评审并作为实现或验收依据。
- `已废弃`：被新基线取代，必须链接替代文档。

“已完成”“已验证”“已通过”必须关联可复核证据，例如命令输出、测试报告、服务日志、截图或发布记录。只完成代码而未完成外部环境验证时，应写“代码已完成，待环境”，不得写成整体已完成。

外部账户、供应商额度、素材授权、真实中间件、操作系统兼容、安装签名和生产凭据等阻塞，使用 `待环境` 或 `blocked-external` 标记，并写明解除条件。HTTP 402、服务不可用和额度不足属于失败链路证据，不能写成真实模型成功。

## 4. 每次文档变更流程

1. 先更新唯一事实源，再按触发矩阵同步下游文档。
2. 更新每份实质修改文档的版本、状态、更新时间和“更新记录”。
3. 将问题、修正和证据登记到 [document-review.md](./document-review.md)。
4. 新增文档加入 [docs/README.md](./README.md) 文档地图；移动或废弃文档同步更新链接。
5. 执行 `pnpm docs:check`；脚本失败时不得将文档变更标记为完成。
6. 进入更高环境前，按 [quality-gates.md](./quality-gates.md) 和 [release-management.md](./release-management.md) 执行对应代码、接口、单元测试和 Playwright 验收。

## 5. 自动化检查

本地和 CI 统一执行：

```powershell
pnpm docs:check
```

检查失败条件包括：

- Markdown 相对链接指向不存在的文件或目录。
- 文档地图没有登记本规则文件。
- 桌宠或 AI 当前事实缺失。
- 当前权威文档出现已废弃的桌宠场景或旧 AI 供应商/模型表述。
- 当前测试报告的接口、冒烟、E2E 和按钮基线与文档地图、发布评估、追溯矩阵不一致。
- 文档引用的根目录 E2E 命令或 `e2e/package.json` 脚本不存在或发生漂移。
- 当前环境配置中的网关入口与本地启动约定不一致。

脚本只扫描当前事实文件，不删除评审记录中的历史说明。历史内容必须保留在有明确日期和评审语境的记录中，不能复制回当前状态段落。
