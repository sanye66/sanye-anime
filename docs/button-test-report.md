## 1. 检测方法

- 收集页面所有可见可交互元素（`button:not([disabled])`、`a[href]`、`[role="button"]`）。
- 逐个点击并捕获：控制台错误、页面异常（pageerror）、请求失败（requestfailed）、页面空白。
- 点击后恢复状态（URL 回退、关闭 dialog、登出后重新登录），再检测下一个按钮。
- 轮播/隐藏 slide 等非当前视图按钮（用户当前不可见）自动跳过，不算失败。
- CAS 登录跳转目标（localhost:8443）未部署属外部环境预期，不计为按钮问题。

## 3. 发现并修复的问题

### 3.1 详情页 slug 路由 Bug（已修复）

首页排期区“查看作品 →”等入口使用 `/anime/blue-hour` 这类 slug 路径，但详情页此前把 slug
直接传给 `/api/v1/anime/{id}` 接口，非数字 slug 导致网关 503。

修复：[animeDetailView.vue](../sanye_client/src/views/animeDetailView.vue) 增加
slug → id 映射（star-sea-echo=1、summer-afterglow=2、blue-hour=4）；数字 id 直接请求；
本地原型虚构作品（如“远方来信”）走本地数据展示，不再发无效请求。

### 3.2 其他说明（非 Bug）

- 右上角“登录”按钮：跳转 CAS（localhost:8443）未部署属预期，跳转逻辑与 service 参数正确。
- hero 轮播非当前 slide 的按钮：用户需先滑动切换，脚本按“非当前视图”跳过。
- 侧边栏收起按钮（‹/›）：点击后状态切换导致文本变化，脚本按“点击生效”判定。
