## 1. 评审对象

目标页面：`https://yhdmtv.cc/p/65395/153/0`。

只读检查结果：页面标题为《你的名字》，页面包含选集链接和一个第三方 `iframe` 播放器；当前页面的 `iframe` 指向外部播放器页面，播放器页面再加载外部 HLS 流。项目当前作品详情页只有作品元数据、角色、相似作品和排期，没有剧集媒体模型、播放器组件或媒体导入接口。

## 2. 范围裁决

本次实现只支持以下范围：

- 由拥有内容权利或已获得授权的运营人员提交 `https` 公开页面地址。
- 抓取页面标题、选集链接、外部播放器 `iframe` 地址等媒体元数据。
- 将元数据保存到项目自己的 PostgreSQL 数据表，客户端通过受控接口展示播放列表。
- 播放器支持外部 `iframe` 播放和浏览器原生支持的直链媒体，提供选集切换、来源页跳转、加载失败和空状态。
- 导入接口只允许配置的来源域名，并由管理端权限与服务间令牌双重保护。

以下内容明确不在范围内：

- 不下载、转码、缓存、镜像或代理第三方视频二进制内容。
- 不绕过登录、验证码、付费墙、Referer 限制、DRM 或其他访问控制。
- 不解析或提取隐藏播放器参数来规避站点正常播放流程；页面可见的外部 `iframe` 地址按原样保存。
- 不默认批量抓取整站，不并发扫描站点，不忽略 robots、服务条款、版权通知或来源方限制。
- 不将目标站点的内容视为已获授权；上线前必须由运营方完成来源授权和版权审查。

## 3. 风险与控制

| 风险 | 等级 | 控制措施 | 验收证据 |
| --- | --- | --- | --- |
| 未授权内容进入目录 | 高 | 管理接口双重鉴权；来源域名白名单；发布前人工审核 | 服务单测、接口体检、管理端权限测试 |
| SSRF 或内网地址探测 | 高 | 仅允许 `https`；来源域名精确白名单；不访问 iframe 指向的第三方流地址 | URL 校验单测 |
| 外部播放器脚本影响客户端 | 高 | `iframe` 使用 `sandbox`、`referrerpolicy=no-referrer`，不允许顶层导航；来源页单独打开 | Playwright DOM 属性断言 |
| 页面结构变更 | 中 | 导入结果允许为空；记录原始来源页；客户端提供失败态和重试/来源页入口 | 导入解析单测、页面 E2E |
| 外部服务不可用 | 中 | 导入接口超时和大小限制；已有元数据仍可浏览；播放器显示失败态 | 超时/空结果测试 |
| 隐私和敏感信息泄露 | 中 | 不保存 Cookie、Header、登录态或页面全文；日志不记录外部响应正文 | 日志检查、代码评审 |

## 4. 评审结论

建议按“元数据导入 + 外部播放器嵌入”实施，暂不实现视频下载或自建流媒体转发。若后续需要本地存储视频，必须另行完成版权授权、存储容量、病毒扫描、内容审核、删除通知和发布合规评审，不得由本任务默认扩展。
