## 1. 检测内容

- **布局**：每页检查 `document.documentElement.scrollWidth - innerWidth`（横向溢出 ≤1px）、关键区块可见、无 JS/控制台/请求错误。
- **双状态**：
  - 未登录：客户端匿名可用（匿名设备链路）；管理端访问受保护页被守卫重定向 `/login`。
  - 已登录：admin 登录后仪表盘、内容管理、用户反馈、任务管理正常。
