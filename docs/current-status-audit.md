## 4. 解除正常使用阻塞的最小顺序

1. 准备明确的隔离集成环境和可写数据范围，对齐网关、前端、CAS 与回调地址，注入合格配置并启动所需服务。
2. 完成该环境首页、搜索、详情、登录、收藏、管理登录/权限、内容发布至索引、文件读写及调度日志的完整回归；真实媒体和 AI 分别记录成功与失败链路。
3. 按 T-R-06 固定提交、产物摘要、配置版本、迁移/备份证据和回滚版本，验证远端门禁与实例对应关系。
4. 按 T-R-07 执行部署和一次实际版本回滚，保存业务验收、健康、故障指标与操作记录。
5. 公开发布前关闭真实 CAS、AI 供应商、版权与法律文案、域名/TLS 等外部门禁；桌宠发布另完成 Windows 系统与安装验收。
