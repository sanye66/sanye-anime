## 2. 发布类型建议

- **当前可达**：内部预览（local/dev 环境）——全量回归 + 三端构建 + 冒烟/E2E 全绿。
- **验收发布（test）**：Docker/ES 基础设施、6 条正式业务索引文档、search 命中和 RAG 检索联调已完成；仍需在目标环境完成数据库连接验收。
- **正式发布（release/prod）**：需 CAS（T-F-01）、域名/TLS（GAP-014）、法律文案（GAP-013）、供应商（GAP-006）。

## 4. 回滚就绪

- 应用：回退上一 release jar/静态资源（当前为 dev 基线，正式发布时固化首个基线）。
- 数据库：禁止反向迁移；先备份（已演练生成 dump），向前修复或 pg_restore（恢复命令见 backup-local.ps1）。
- 配置：还原环境变量；密钥轮换需同步撤销。
