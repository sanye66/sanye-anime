## 1. 使用说明

- 每个产品能力行给出：产品编号 → 功能规格 → 任务 → 实现接口/模块 → 测试证据 → 验收状态。
- 验收状态：已完成（含证据）/ 进行中 / 待环境 / 待开始。
- 追溯用于：需求变更影响分析、发布验收、缺口识别（未实现的需求必须登记 gap-register）。

## 4. 缺口校验

- 产品需求中“已冻结 P0”项必须在本矩阵有对应任务与状态；缺失即登记 gap-register。
- 任务“已完成”必须有测试证据（本矩阵“测试证据”列指向报告/数量）。
- 状态为“待环境”的任务不标记完成，避免验收误判。
