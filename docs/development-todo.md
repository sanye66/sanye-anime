## 1. 使用规则

### 1.1 状态定义

| 状态 | 含义 |
| --- | --- |
| `待开始` | 尚未开始处理 |
| `进行中` | 已经开始处理，但验收条件尚未全部满足 |
| `待环境` | 需要真实数据库、缓存、部署环境或外部账号 |
| `待代码` | 需要先完成应用代码、脚本或自动化配置 |
| `已完成` | 已有可复查证据，并满足该项验收标准 |

### 1.2 完成规则

1. 每项待办必须同时记录实现变更、命令结果、测试记录或外部环境证据。
2. 仅完成 Maven 构建或静态检查，不能视为真实登录、权限、存储或任务执行验收通过。
3. 依赖外部环境的事项，在环境未准备完成前保持 `待环境`，不得提前标记为 `已完成`。
4. 单人开发按照依赖顺序推进，先关闭正式编码前置门禁，再进入工程任务、业务代码和发布能力建设。
