## 2. 运行模型

建议采用 Vue + Capacitor + Kotlin 设备能力层。调用链：页面 → 安卓业务适配 → 设备端来源解析或本地数据库 → 播放器。手机直接访问支持的内容来源，不访问 Windows 或自建业务服务器。

设备端来源适配实现关键词搜索、详情、线路、集数和临时播放地址解析。迁移时参考现有 `ExternalSearchService`、`MediaImportService` 与 `HttpMediaPageFetcher` 的行为及回归样例，不携带 Spring 运行环境。使用结构化解析器，不执行来源页面脚本或下载任意代码。支持取消、总超时、并发上限与失败分类；来源规则随应用版本维护。

原生 HTTP 可以用于受限来源请求，但不代表 HLS.js 已能播放。须分别验证清单、分片、初始化段、字幕及授权密钥的 CORS、请求头和 Cookie；必要时采用 AndroidX Media3。禁止关闭证书校验、全局放开明文流量或开放任意 URL 桥接代理；跳转逐跳校验域名，拒绝非预期协议和本机/私网目标，不向无关域名转发凭证。

不把可选远程 API 作为默认补救依赖。特殊请求头和页面解析不必然需要服务器，先验证设备端方案；确实只能远端完成的能力记录为未支持，引入服务器必须另行决策。

## 3. 技术方案

| 层 | 首选方案 | 约束 |
| --- | --- | --- |
| 页面 | Vue 3 + TypeScript + Vite | 复用 `sanye_client`，增加 `android` 构建模式 |
| 安卓壳 | Capacitor Android | 使用 Android Studio/Gradle 生成 APK；不改 Windows Electron 配置 |
| 播放 | HTML5 video + HLS.js 或 AndroidX Media3 | A0 按真实来源选定主路径，不默认维护双播放器 |
| 本地数据 | SQLite 插件或窄接口原生桥接 | A0 锁定实现；IndexedDB 仅用于原型，不以 WebView 缓存代替数据库 |
| 普通设置 | Capacitor Preferences | 仅非敏感选项，不提供加密保证 |
| 敏感数据 | 如需要，使用 Android Keystore 支持的加密存储 | 不在源码、日志、APK 资源中放置凭证 |
| 网络 | 设备端 HTTP/解析与播放器请求层 | 不依赖网关；请求有界、可取消，日志不保留敏感播放 URL |

### 3.1 工程与工具链

计划新增 `sanye_android/` 作为 `sanye_client` 的原生交付容器，不增加第四套核心业务工程；其下 `android/` 为框架生成目录。前端适配计划位于 `sanye_client/src/platform/android/`，独立输出 `dist-android`，本地加载打包页面并验证深层路由与返回。按实际复用需求提取接口，不复制整套前端，也不把安卓判断塞进 `desktopMode`。

产品名保持 `sanye_anime`，拟定 `applicationId` 为 `com.sanye.sanye_anime`；如新增 JavaScript 包则使用 `@sanye/sanye_android`。以上目录与标识均为计划，尚未创建。

最低系统建议 Android 10（API 29），布局从 360 CSS px 验证；A0 结合目标手机与插件确定支持范围。沿用仓库 Node.js 26.5.0、pnpm 10.15.0；Android Studio、SDK、Capacitor、AGP、Gradle 与 JDK 在 A0 验证兼容组合并锁定。仓库 Java 21 基线不能替代 AGP 兼容检查，如需独立 JDK，只配置安卓构建，不改全局环境。

### 3.2 数据与生命周期

保存目录、来源映射、收藏、集数进度和设置，以来源标识、作品标识、集数标识关联数据，线路单独存储，不能只用片名或显示集号去重。播放地址过期后重新解析，不把短期令牌作为永久数据。具体字段与迁移在实施前登记到[数据库设计](./database-design.md)，桥接方法与错误语义登记到[接口契约](./api-contract.md)，不另建重复事实源。

迁移使用事务并先备份，失败保留原库并停止写入，禁止自动删库重建。进度节流落盘，在暂停、切集、进入后台时补写；系统杀进程后恢复最近成功提交值。处理旋转、音频焦点、耳机断开和后台恢复，防止双播放器及重复监听。文件导入采用系统选择器，不要求全盘权限；媒体缓存与个人数据分开清理。

## 4. 分阶段任务

### 4.0 Windows 能力复用矩阵

| 安卓板块 | 可直接复用 | 需要重写/适配 | 完成证据 |
| --- | --- | --- | --- |
| 页面与路由 | Vue 页面结构、路由命名、状态文案和移动端 CSS | 安卓壳生命周期、返回键、深层链接、权限提示 | 页面构建、旋转/返回真机记录 |
| 搜索 | 关键词规范化、别名展开、标题去重、类型筛选规则 | 服务端 `ExternalSearchService` 改为设备端请求；取消、超时、并发和短缓存 | 固定 HTML 样例 + 真实来源搜索；旧请求取消、失败不缓存 |
| 预览 | `AnimeUrlImportService` 的预览零写入规则、元数据字段和错误分类 | 白名单请求、受限跳转、响应大小限制和 HTML 结构化解析 | 预览后本地库无新增；超时/跳转/超限拒绝 |
| 导入 | 现有来源 URL、作品、集数、线路的数据语义；完整解析后整体替换 | 管理端身份头和服务端写库不能搬运；改为用户显式保存、本地事务和稳定 ID | 重复导入更新同一记录；解析失败保留旧快照 |
| 播放 | 选集、线路排序、清晰度和进度语义；HLS/iframe 分类 | WebView CORS、Cookie、请求头、横屏、后台和原生 Media3 适配；iframe 不默认继承全部能力 | 代表作品首帧/30 秒/拖动/切集/后台恢复，记录每条线路实际能力 |
| 收藏与历史 | 现有页面行为、进度更新时机和展示规则 | PostgreSQL/JDBC 改为 SQLite；迁移、事务、清理边界 | 重启/杀进程/升级后数据保留，集数线路不串 |
| 设置与账号 | 设置项及未登录降级文案 | CAS、网关会话和服务间令牌不进入安卓首版；敏感值需 Keystore | 无服务器启动；敏感信息不出现在日志/APK |
| Windows 桌面能力 | 仅复用媒体交互和回归样例 | Java、PostgreSQL、Electron 主进程、托盘和本地服务完全排除 | APK 包内无桌面运行时，进程清单与依赖检查 |

复用以“行为契约”和纯前端代码为主，不复制 Spring 网关、集中缓存、服务间身份或 PostgreSQL 实现。现有 Windows 测试可转为固定样例和契约回归，但不替代安卓设备证据。

### A0 方案验证

- 在 `sanye_android/android/` 建立工程与 debug 构建，锁定工具链及插件。
- 在至少一台 Android 10+ 真机验证 WebView、返回键、文件选择和 HLS 播放。
- 用受控 HLS/MP4 及实际来源验证搜索到播放，包含多线路、重定向、过期地址和异常清单，不虚构已有来源数量。
- 输出设备矩阵、解析样例、网络证据、主播放器选择与不可支持原因；缺少真机或来源条件标记 `待环境`。套壳成功不代表方案成立。

验收重点：用一条直接 `.m3u8` 和一条 iframe 样例区分 WebView 与 Media3 主路径；验证清单、分片、字幕、请求头/Cookie、首帧、3 秒播放、切后台恢复和失败重试。

### A1 本地数据与基础页面

- 实现 SQLite 存储、迁移与设备端业务适配。
- 迁移外部搜索、详情及线路解析，替换安卓对 `/search/external`、`/anime/external-preview`、`/anime/import-url` 的依赖；排查首页、排期、收藏及认证的其余服务端调用。
- 接入内置目录和用户导入数据，覆盖空数据、损坏数据、迁移失败和清除数据。
- 完成首页、仓库、搜索、详情和播放页面的安卓布局适配。

导入链路为：搜索结果 → 详情预览（不写目录）→ 用户点击保存 → 本地事务写入作品/集数/线路 → 本地详情。直接观看是另一条分支：预览成功即可播放，不强制先导入。开始观看后可记录最小历史快照，不能因此自动加入片库；用户收藏临时作品时原子保存必要作品信息与收藏关系。解析失败不得写入半成品，新快照完整解析成功前保留旧快照。

### A2 播放体验

- 实现 HLS/MP4 播放、清晰度切换、选集、进度保存、全屏、系统返回和后台暂停。
- 按产品草案先默认关闭 Anime4K、实时补帧和 FFmpeg 插帧，有性能与功耗证据后评估实验入口。
- 对不支持的媒体类型、网络超时、证书错误和源失效提供可操作错误提示。

回归必须覆盖当前线路 ID 优先、集数与备用线路不混淆、电影语言线路不串到相邻集、过期地址重新解析，以及播放失败后回到详情仍可重试。

### A3 发布候选

- 生成 debug APK 与独立安卓签名的 release APK；配置递增 `versionCode`、展示版本、应用标识和图标。
- 执行类型检查、前端构建、安卓 Gradle 构建、真机冒烟和安装升级测试。
- 记录 APK SHA-256、证书摘要、构建环境、设备矩阵及限制。密钥在仓库外备份，升级保持签名身份；执行 `apksigner verify --verbose --print-certs` 和同签名覆盖安装。debug 签名不能替代正式交付身份；上架 AAB 与发布另行授权。

顺序为 A0 → A1 → A2 → A3，当前全部未实施。本文为工作分解，实际执行状态与证据后续登记[开发任务清单](./development-tasks.md)，不建立第二套状态台账。工期在 A0 确定来源迁移量和播放器路径后估算。

### 4.2 AND-M01：工程、启动与导航

- **参考**：[路由](../sanye_client/src/router/index.ts)、[应用壳](../sanye_client/src/App.vue)、[构建配置](../sanye_client/vite.config.ts)。复用页面路由名称与可适配布局，安卓另设启动入口、构建输出和能力声明。
- **开发顺序**：锁定工具链 → 加载本地前端 → 初始化存储 → 注入设备能力 → 恢复路由。存储未就绪前不挂载依赖数据库的业务页面；异常显示可重试状态，禁止循环启动。
- **平台接线**：应用启动时选择一次安卓业务实现；页面不直接判断 Windows/Android 后拼 HTTP 地址。小屏导航适配手势区、状态栏、软键盘和横竖屏；顶部返回与系统返回走同一栈，首页返回遵循 Android 行为，不借用 Windows 托盘机制。
- **失败与验证**：覆盖首次启动、升级启动、外部链接进入、系统杀进程后重开、初始化失败、无网络。来源 URL 只作为经校验的数据，不允许加载带原生桥接权限的任意远端页面；普通外链交给系统浏览器或无桥接隔离页面。

### 4.3 AND-M02：本地数据与身份映射

- **参考**：[数据类型](../sanye_client/src/api/types.ts)、[收藏接口](../sanye_client/src/api/favorite.ts)、[播放器缓存](../sanye_client/src/video/playerCache.ts)。复用字段含义，不照搬 PostgreSQL 表、服务端用户身份或 `localStorage` 临时缓存的保留策略。
- **开发顺序**：定义本地作品身份 → 来源映射 → 集数与线路快照 → 收藏/历史 → 迁移。Windows 页面中的固定作品 ID 和 `/admin-profile` 路径须通过安卓数据映射或资源解析替换，不能直接当手机本地记录使用。
- **一致性**：目录保存和线路替换在事务内完成；同一来源作品重复导入更新原记录，标题相同但来源不同不自动合并。同一数据库为首页、仓库、详情和“我的”的事实源，写入提交后再通知页面刷新。
- **恢复与验证**：迁移前备份并检查磁盘空间；迁移失败、存储已满、写入中断时保留旧版本，不能以清库恢复掩盖错误。验证升级前后收藏/进度、重复导入、并发收藏和无效备份拒绝。数据库字段、桥接签名与版本在实施前写入既有权威文档。

### 4.4 AND-M03：来源请求与解析

- **参考**：Windows 的 `ExternalSearchService`、`AnimeUrlImportService`、`MediaImportService`、`HttpMediaPageFetcher`。详细文件与测试索引见第 5.1 节。
- **开发顺序**：来源清单与能力声明 → URL 规范化/受限跳转 → 搜索解析 → 详情元数据 → 集数/线路 → 临时播放地址。来源声明是否支持搜索、排期、直接媒体或 iframe，缺失能力有明确返回状态。
- **迁移规则**：参考当前关键词别名、去重、部分成功、请求合并和短缓存行为；响应体与总时间有上限，跳转逐跳校验。将 `player_aaaa`、`temLineList` 等现有解析规则转换为可测试的设备端实现，不用 `eval` 执行页面代码。
- **重点回归**：保留“当前线路 ID 优先”“电影语言线路不能误当历史集数”“相邻集不能变成本集备用线路”的 Windows 回归样例。页面完整解析且验证成功才生成新快照；过期地址按稳定来源身份刷新，不按旧签名 URL 去重。
- **失败恢复**：区分来源不支持、网络不可达、限流、解析结构变化和没有可播放线路。自动重试有界且仅用于可恢复读取，尊重来源限流；失败不覆盖缓存为假空结果，不触发无限切源。媒体 CDN 域名规则与详情页来源规则分开验证。

### 4.5 AND-M04：搜索

- **参考**：[搜索页面](../sanye_client/src/views/searchView.vue)、[搜索 API](../sanye_client/src/api/search.ts)。沿用输入规范化、类型筛选、优先结果与完整结果分步展示、取消过期请求；把服务端调用换成设备端能力。
- **开发顺序**：SQLite 本地关键词查询 → 外部来源搜索 → 合并展示与来源标记 → 分页 → 详情/直接观看导航。结果身份使用来源作品键，不以片名简单跨来源去重；季度聚合采用元数据，不能沿用特定作品的固定服务端 ID。
- **并发与状态**：每次搜索递增请求代次，切词/筛选/离页取消旧请求；原生桥接支持取消，无法立刻终止时也必须丢弃旧代次结果。同词请求合并、成功短缓存、容量有上限；多来源部分失败时展示已成功结果和失败状态。
- **验收**：输入法中文组合输入、快速切词、旧请求晚到、空输入、空结果、断网、部分来源失败、翻页后返回位置。安卓不沿用 Web 端演示数据回退，网络失败不能被样例目录遮盖；本地搜索在断网下仍可用。

### 4.6 AND-M05：预览、详情与导入

- **参考**：[详情页](../sanye_client/src/views/animeDetailView.vue)、[番剧 API](../sanye_client/src/api/anime.ts)。复用详情布局、请求取消、季度/集数选择和错误展示；临时预览与已保存作品区分身份。
- **两条分支**：直接观看只解析并创建临时会话，不自动入库；显式保存把完整作品与剧集快照一次提交。临时作品被收藏时只保存必要本地元数据和来源映射，不复制所有媒体内容。
- **更新策略**：重复导入保持本地作品 ID 和用户收藏/进度；更新剧集按稳定来源集数标识匹配。无法确定旧新集数对应时保留旧历史并标记不可恢复，不凭列表位置或相同集号绑定进度。
- **失败与验证**：无集数、仅 iframe、重复点击导入、离页后请求返回、解析一半失败、保存失败均可恢复；取消/失败不产生半套目录。返回搜索保留关键词和位置，保存后首页、仓库和详情看到同一条记录。

### 4.7 AND-M06：播放器与手机生命周期

- **参考**：[详情播放器](../sanye_client/src/views/animeDetailView.vue)、[拖动控制](../sanye_client/src/video/seekControl.ts)、[缓存与进度](../sanye_client/src/video/playerCache.ts)、[HLS 分片缓存](../sanye_client/src/video/hlsFragmentCache.ts)。只共享纯逻辑与事件含义；Media3 路径不能假设 ArtPlayer 控件可直接复用。
- **会话契约**：准备 → 就绪 → 播放/暂停 → 缓冲 → 结束/失败 → 释放。使用会话代次约束异步解析、播放器事件和进度写入，切集先保存旧进度并释放旧实例，新会话就绪后再恢复对应进度。
- **开发顺序**：基础 HLS/MP4 → 真实清晰度/线路/集数 → 拖动与恢复 → 全屏/旋转 → 音频焦点与后台暂停 → 释放与故障恢复。切画质尽量保留当前会话；切线路需核对同一集与时长，再决定是否继承进度，不能跨剪辑版本盲目恢复。
- **iframe 边界**：嵌入页不能使用应用原生桥接，非受信导航转系统浏览器；跨域播放器若没有可信事件协议，则暂停、进度、清晰度和画质增强不可假定可控。A0 验证可控播放方式；无法满足后台停止要求时离开前销毁嵌入实例，并明确该线路无法精确续播，不上报伪造播放事件。
- **验证**：播放推进和解码尺寸、拖动命中、连续切集不串音、切后台不继续隐性播放、耳机断开、来电/音频焦点、旋转、网络切换、结束后重播。增强功能另做性能门禁，菜单目标帧率不能当真实屏幕帧率证据。

### 4.8 AND-M07：首页与番剧仓库

- **参考**：[首页](../sanye_client/src/views/homeView.vue)、[首页聚合](../sanye_client/src/composables/useHomeFeed.ts)、[番剧仓库](../sanye_client/src/views/animeRepositoryView.vue)。沿用卡片、分类筛选、分页和收藏反馈，数据改为 SQLite 查询与设备来源刷新。
- **首页**：近期导入、已有目录和继续观看使用本地事实；静态推荐若保留须解析到实际可用条目，不携带 Windows 固定 ID、旧“已验证集数”或失效封面路径。没有可信热度来源时不把演示热度当真实统计。
- **仓库**：分页/筛选/排序由同一查询返回列表和总数；导入成功只刷新受影响查询，防止重复条目和回到空白页。封面失败用占位资源，封面下载不得阻塞文字与播放入口。
- **验证**：首次空库、只有本地库、来源离线、导入后刷新、筛选无结果、最后一页变动、收藏提交失败。页面显示的收藏状态与“我的”一致，不维护各自独立数组作为持久事实。

### 4.9 AND-M08：收藏、历史与继续观看

- **参考**：[我的页面](../sanye_client/src/views/mineView.vue)、[收藏/历史接口](../sanye_client/src/api/favorite.ts)、[进度缓存](../sanye_client/src/video/playerCache.ts)。现有历史接口以作品访问为主，具体秒数存于播放器缓存；安卓需整合为可恢复的本地观看记录，不能直接声称已有完整能力。
- **开发顺序**：幂等收藏读写 → 收藏分页 → 播放事件记录 → 秒数与集数保存 → 最近观看排序 → 从历史恢复。临时作品历史保留最小来源快照，不自动加入番剧仓库；已保存作品复用本地身份。
- **事件边界**：建议在真实播放推进后登记观看，预览失败不算观看。进度包括作品、集数、线路/版本及更新时间；近结尾和已看完有独立规则，不在每次 `timeupdate` 无节制写库。删除历史不删除收藏，取消收藏不清除进度。
- **失败与验证**：双击收藏、写入失败回滚、离页返回、杀进程、存储满、临时 URL 过期后重解析、已删除来源恢复失败。跨页面状态以提交后通知更新，不因乐观 UI 显示成功就判定保存成功。

### 4.10 AND-M09：排期与更新

- **参考**：[排期页](../sanye_client/src/views/scheduleView.vue)、[周排期接口](../sanye_client/src/api/schedule.ts)。复用星期切换和列表布局；现有失败回退包含本地示例日期，提醒只是在页面内切换数组，不能当手机系统通知已实现。
- **开发顺序**：明确来源时间字段与时区 → 本地周排期查询 → 手动刷新 → 关联本地作品和详情。来源没有播出时间时返回未知/空状态，不按静态样例编造更新日期。断网可以保留最近有效排期并标明更新时间。
- **可选通知**：如后续纳入通知，另做权限申请、拒绝降级、调度去重、取消、重启和时区改变测试；无服务器不能承诺实时推送，系统后台调度也不能承诺精确到秒。首版的关注标记不能写成系统通知能力。
- **验证**：跨周与时区、已完结作品、刷新失败、空排期、同作品重复记录、点击后的身份映射。未适配来源时说明能力限制，不阻断其他板块。

### 4.11 AND-M10：设置、缓存与诊断

- **参考**：现有播放器设置、`playerCache.ts` 和 `hlsFragmentCache.ts` 的有界缓存思路。将应用偏好、个人数据、元数据缓存、封面与媒体缓存分开管理；参数上限按 A0/A2 实测确定。
- **开发顺序**：设置读写 → 播放器能力反馈 → 缓存大小统计 → 清理 → 脱敏诊断。清理前确认作用域，正在播放的资源协调释放；清理媒体缓存保留 SQLite 个人数据，恢复默认设置不等于清库。
- **诊断**：记录应用/系统/WebView/播放器版本、来源标识、错误阶段和耗时；不记录完整签名地址、Cookie 或凭证。复制或导出日志由用户显式触发，不自动上传。
- **恢复与验证**：磁盘不足、清理取消、文件被占用、偏好损坏、插件暂不可用、敏感地址脱敏。备份恢复若后续纳入，采用带版本清单、结构校验和事务恢复，不依赖 Windows PostgreSQL 备份。

### 4.13 AND-M12：测试、构建与升级

- **复用方式**：参考 Windows 的定向回归、构建清单和包内资源检查，不携带 Electron 签名、PostgreSQL 模板或 Windows 安装脚本。测试代码中的桌面本地服务、Cookie 和浏览器假设需替换为 Android 环境。

### 4.14 端到端链路与失败出口

| 链路 | 必须贯通的步骤 | 失败出口与数据约束 | 涉及板块 |
| --- | --- | --- | --- |
| 冷启动 | 本地资源 → 存储检查/迁移 → 能力注入 → 首页查询 | 初始化失败可重试，网络异常不阻止浏览本地数据 | M01、M02、M07 |
| 在线直接看 | 关键词 → 来源搜索 → 只读预览 → 集数/线路 → 播放 → 历史快照 | 请求可取消，失败保留搜索位置；不强制导入，不伪造观看历史 | M03–M06、M08 |
| 保存到本机 | 地址或搜索结果 → 预览 → 显式保存 → 事务提交 → 仓库/详情刷新 | 重复保存更新同一记录，失败不污染旧目录 | M02–M05、M07 |
| 收藏闭环 | 首页/仓库/详情 → 本地收藏事务 → 我的分页 → 详情 | 写入失败回滚按钮；跨页显示一致，临时作品先保存最小元数据 | M02、M05、M07、M08 |
| 继续观看 | 播放推进 → 保存进度 → 暂停/重开 → 历史 → 刷新临时地址 → 同集恢复 | 来源不可用保留记录；跨集、跨剪辑版本不错误续播 | M03、M05、M06、M08 |
| 来源更新 | 手动刷新 → 新快照校验 → 本地合并 → 详情/排期更新 | 获取失败保留上次有效数据及更新时间，不丢收藏与进度 | M02、M03、M05、M09 |
| 缓存清理 | 设置统计 → 选择缓存类别 → 停用对应资源 → 清理 → 重载 | 用户数据保持；不以缓存清理掩盖数据库损坏 | M02、M06、M10 |
| 安装升级 | 校验签名 → 同身份覆盖安装 → 数据迁移 → 冷启动 → 收藏与续播验证 | 错签名拒绝升级；迁移失败保留数据并提供修复路径 | M01、M02、M08、M12 |

链路验收以用户操作和落盘状态共同判断，不能只看请求成功、按钮变色或播放器容器出现。

## 5. 验收标准

产品验收见[需求草案](../product/android-requirements.md)，工程完成还需以下证据：

- `pnpm --filter @sanye/sanye_client typecheck` 与 `pnpm --filter @sanye/sanye_client build` 通过。
- 前端进入更高环境前执行根目录 `pnpm typecheck` 与 `pnpm build`，另外执行安卓专用前端构建；普通网页构建不替代安卓构建。共享代码影响 Windows 时补充对应桌面回归。
- 在计划目录 `sanye_android/android/` 执行 `./gradlew.bat assembleDebug`、`./gradlew.bat lint`、`./gradlew.bat testDebugUnitTest`；候选另执行 `./gradlew.bat assembleRelease`。这些命令当前未执行，工程尚不存在。
- 两台不同厂商真机安装运行，覆盖选定最低系统与较新系统/WebView；模拟器不代替解码、触控与功耗验证。
- 代表作品至少 3 个：搜索/目录进入详情、选集、首帧、连续播放 30 秒、拖动、全屏和返回均通过。
- 30 秒仅为冒烟，增加至少一段 30 分钟持续播放、切集与后台恢复，记录温度、内存和丢帧；不据此承诺所有设备性能。
- 电脑关闭、未配置远端业务 API 时完成上述流程，检查不存在隐性 Windows/网关请求。
- 固定样例验证分页、重复集数、多线路、超时和异常；数据库验证迁移失败恢复、重复导入、强制结束后的持久化；样例测试与真实外网证据分开记录。
- 断网、源失效、无权限文件、空目录和应用重启场景有截图或自动化日志。
- 明确区分“本地代码通过”“安卓模拟器通过”“真实设备通过”和“外部播放源待环境”；任何一项没有证据都不能写成整体完成。

## 6. 风险与决策门

- **播放源风险**：先验证设备端请求、解析与原生播放器。确实需要远端的能力保持未支持，不私自改变无自建服务器边界。
- **性能风险**：不同 SoC 对高码率 HLS、4K、WebGL 和补帧支持差异较大；首版以稳定播放优先，增强功能必须可关闭并有降级。
- **存储风险**：本地数据库升级和媒体缓存可能占用大量空间；首版不默认永久缓存视频，提供清理入口。
- **发布风险**：release 签名、商店审核和版权材料属于 `待环境`，不由本地构建成功推导。
