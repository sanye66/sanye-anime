## 1. 已确认边界

Windows 与安卓各自独立使用，安卓无需电脑开机、无需连接 Windows 客户端，也不要求用户购买服务器。两端个人数据各自保存，不默认同步。在线搜索、更新和在线观看视频仍需互联网。

本文是安卓专项草案。以下首版取舍为建议，尚未冻结，不变更 Windows 功能与验收要求。范围确定后按文档变更规则同步现有产品需求、功能规格、MVP、决策、任务和追溯记录。

## 2. 建议首版范围

| 编号 | 功能 | 预期行为 |
| --- | --- | --- |
| AND-01 | 启动与本地浏览 | 无需登录；断网可浏览已有目录、收藏和历史，首次无数据显示空状态 |
| AND-02 | 搜索与详情 | 区分本地和网络结果；来源不可用时保留本地结果和重试入口，不把失败显示为无作品 |
| AND-03 | 导入与更新 | 支持适配过的公开作品地址；预览线路和集数后保存，重复导入不重复建档，不支持的来源显示原因 |
| AND-04 | 基础播放 | 选集、线路切换、拖动、全屏和横竖屏；清晰度按源实际提供展示 |
| AND-05 | 个人数据 | 收藏、进度和设置重启后保留；清理缓存不删除个人数据 |
| AND-06 | 手机操作 | 返回优先关闭弹层或退出全屏，再返回页面；切后台暂停，恢复后由用户继续播放 |
| AND-07 | 首页与仓库 | 展示真实本地目录，支持筛选和分页；导入、收藏后各页面一致，空库不以演示作品冒充已有作品 |
| AND-08 | 继续观看 | 直接观看不强制保存到片库；实际观看后保留历史，能够控制进度的线路可从对应集数继续 |
| AND-09 | 排期与更新 | 展示来源提供的排期及更新时间；缺少信息时显示未知，刷新失败保留上次有效结果，不承诺无依据的实时通知 |
| AND-10 | 设置与诊断 | 偏好重启后保留；缓存与个人数据分开清理，错误可重试，诊断信息由用户主动导出 |

首页和仓库只展示有来源的目录；预置样例不能冒充网络搜索结果。建议延后账号同步、AI、管理审核、后台连续播放、画中画和完整视频离线下载。手机画质增强与高帧率处理需单独评估，建议首版默认关闭。上述建议不表示用户已确认删减功能。

## 3. 完整使用链路

下列是对现有首版建议的细化，不表示 Windows 全部功能已承诺移植。

| 场景 | 正常过程 | 异常后可继续的操作 |
| --- | --- | --- |
| 搜索后直接看 | 搜索 → 预览 → 选集/线路 → 播放，不强制先保存作品 | 搜索位置保留，可重试或换受支持线路；失败不产生假观看记录 |
| 保存作品 | 搜索结果或作品地址 → 预览 → 明确保存 → 仓库与详情可见 | 失败保留原数据，重复操作不重复建档 |
| 收藏与回看 | 任意作品入口收藏 → 我的收藏 → 同一作品详情 | 收藏失败恢复原状态，其他页面不会显示假成功 |
| 继续观看 | 播放 → 暂停/关闭 → 我的历史 → 对应集数继续 | 来源失效保留历史；不支持精确续播的线路明确说明，不跳错集 |
| 更新与排期 | 查看已有作品 → 刷新 → 新信息出现在详情/排期 | 无网络保留最后有效数据和时间，不把旧内容显示为刚更新 |
| 清理与升级 | 清理媒体缓存或覆盖升级 → 返回应用 → 收藏和历史仍在 | 数据恢复失败显示原因，不自动清空个人数据 |

收藏、保存作品和观看历史是不同动作：直接观看不会自动加入番剧仓库；收藏尚未保存的作品会保留必要作品信息。查看预览不算已观看；取消收藏不删除观看进度，删除历史不取消收藏。不能控制播放进度的外部线路只展示其实际支持的能力。

## 4. 产品验收

- 电脑关闭时仍能启动、浏览本地数据；手机有网络时完成支持来源的搜索到播放。
- 断网、搜索无结果、来源失效、导入失败和本地空数据各有状态与恢复入口。
- 收藏、设置和已保存进度在重启与系统回收后保留，不同集数和线路不串用进度。
- 返回、旋转和后台恢复不产生重复播放或跳错集；覆盖升级保留个人数据。
