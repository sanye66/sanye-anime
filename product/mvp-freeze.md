## 1. 冻结结论

`sanye_anime` 首版按三个产品端分别冻结范围：客户端 `sanye_anime`、官网 `official`、管理平台（RuoYi）。优先级定义：

| 优先级 | 含义 |
| --- | --- |
| P0 | 首版必须完成，缺少会破坏主流程 |
| P1 | 首版建议完成，可在首轮内测后补齐 |
| P2 | 后续版本功能，进入开发前重新评估 |

本清单是范围归属的权威来源：每项 P0 功能有唯一归属平台、验收描述和依赖；详细交互与状态以 [功能详细说明](./feature-specification.md) 和 [页面状态矩阵](./page-state-matrix.md) 为准。

## 2. 客户端（sanye_anime）冻结清单

### 2.1 P0

| 编号 | 功能 | 验收描述 | 依赖 |
| --- | --- | --- | --- |
| C-P0-01 | PC 主窗口与壳层（左侧导航、顶部工具栏、用户区） | 1440/1280/1100 布局可用；导航可折叠；顶部搜索可提交；未登录可浏览公开内容 | 无 |
| C-P0-02 | 首页（精选/日漫/剧场版、Banner、热门新番、作品卡片、排行榜与排期入口） | 分区可浏览；图片失败不破坏布局；空分区隐藏；卡片可进入详情 | 内容数据（GAP-004） |
| C-P0-03 | 搜索结果页 | 有结果、无结果（引导 AI 找番）、失败三种状态明确；筛选可用 | 搜索能力（代码已完成，Elasticsearch 本地联调通过；正式环境仍需目标环境验收） |
| C-P0-04 | 番剧仓库（浏览全部作品） | 关键词、类型、状态、年份组合筛选；无结果提供清除筛选 | 内容数据（GAP-004） |
| C-P0-05 | 作品详情页 | 信息、收藏、问 AI、相似作品、返回路径；下架时保留说明并隐藏失效入口 | 内容数据（GAP-004） |
| C-P0-06 | AI 工作区（空状态、快捷任务、文本对话、回答过程状态机、推荐卡片、历史会话打开/删除） | 回答过程状态机按 [页面状态矩阵](./page-state-matrix.md) 第 7 节实现；停止/失败/重试不产生重复问题 | AI 供应商与额度（GAP-006） |
| C-P0-07 | 从作品详情进入 AI 并返回 | 进入后展示当前作品上下文；返回恢复原会话与滚动位置 | C-P0-05、C-P0-06 |
| C-P0-08 | 登录引导、收藏、我的页面基础结构 | 未登录可浏览并体验有限 AI；收藏与个人数据需登录 | 账户服务 |
| C-P0-09 | 页面状态全覆盖 | 空数据、加载、失败、离线、无权限、下架等状态按状态矩阵逐页实现 | 页面状态矩阵 |

## 7. 变更规则

1. 冻结期内新增需求默认进入 P1 或 P2，除非它能消除 P0 风险或修复发布阻塞项。
2. 范围变更必须记录到 [决策记录](../docs/decision-log.md)，并同步更新本清单、产品需求文档和功能详细说明。
3. P1/P2 升为 P0 必须说明理由、验收标准和依赖，经决策后生效。
4. 本清单只登记归属与依赖；每项 P0 的详细验收以功能详细说明和页面状态矩阵为准。
