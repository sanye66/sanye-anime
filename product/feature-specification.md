## 1. 文档使用方式

本文档只描述产品功能、页面结构、交互规则和用户体验。每个功能条目包含：

- 功能目的。
- 用户入口。
- 页面内容。
- 操作规则。
- 空状态、成功状态和失败状态。
- 产品验收标准。

优先级说明：

| 优先级 | 含义 |
| --- | --- |

## 3. 公共壳层功能

### PC-001 客户端启动

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 点击客户端图标或打开 PC 页面 |
| 目的 | 进入可用的首页工作区 |

#### 操作规则

1. 展示简洁启动画面，不使用长时间停留的装饰动画。
2. 检查上次打开的位置、窗口尺寸和用户显示偏好。
3. 默认进入首页；如果用户上次正在 AI 对话，可以提供“继续上次对话”的入口。
4. 首页内容未准备好时展示骨架，不显示空白窗口。

#### 状态

- 启动成功：进入首页。
- 内容准备中：展示骨架和加载提示。
- 无法加载：进入首页错误状态，提供重新加载。
- 用户状态失效：保持公开内容可浏览，进入需要账户的操作时再提示登录。

#### 验收标准

- 启动后始终能进入首页或明确的错误页面。
- 不因为某个内容区加载失败而阻塞整个窗口。
- 上次窗口尺寸不会导致内容被截断或导航消失。

### PC-002 左侧主导航

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 位置 | 窗口左侧固定区域 |

#### 导航项

- 品牌标识。
- 首页。
- AI。
- 我的。
- 设置。

#### 操作规则

- 当前入口使用青色图标、文字和浅色背景。
- 鼠标悬停时显示背景反馈和完整文字。
- 窗口宽度较小时可以折叠为图标栏，悬停后显示文字。
- 切换到 AI 时保留当前会话；首次进入显示 AI 空状态。
- 切换入口不应重复创建会话或丢失输入草稿。

#### 验收标准

- 左侧导航始终可见或可通过折叠按钮恢复。
- 导航文字、图标和选中态不重叠。
- 键盘 Tab 可以依次访问导航项。

### PC-003 顶部工具栏

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 内容

- 当前页面标题或页面路径。
- 全局搜索框。
- 最近访问入口。
- 消息或系统提醒入口。
- 用户头像、昵称和登录状态。

#### 操作规则

- 首页顶部显示搜索框，其他页面保留缩小后的搜索入口。
- 搜索框获得焦点时可展开为更宽的搜索面板。
- 顶部工具栏固定在内容区上方，不随内容列表消失。
- 长标题截断但支持悬停查看完整内容。

### PC-004 全局搜索入口

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 顶部搜索框、快捷键 |

#### 支持搜索

- 作品名称。
- 作品别名。
- 角色名称。
- 题材和标签。

#### 操作流程

1. 用户点击搜索框或按搜索快捷键。
2. 输入关键词。
3. 搜索面板展示历史记录、热门搜索和匹配建议。
4. 用户按 Enter 或点击结果进入搜索结果页。
5. 无结果时提供“让 AI 帮我找”。

#### 输入规则

- 去除首尾空格。
- 空内容不能提交。
- 支持中文、英文、数字和常见作品符号。
- 搜索面板最多展示一页可阅读的建议，更多结果进入结果页。

### PC-005 最近访问

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |

- 展示最近打开的作品、榜单、排期和 AI 会话。
- 按最近访问时间倒序排列。
- 点击后回到对应页面。
- 支持删除单条记录和清空全部。
- 页面不存在或作品下架时，展示不可用提示而不是空白页面。

### PC-006 用户区

#### 未登录状态

- 展示“登录”按钮。
- 点击后打开登录窗口或登录页。
- 用户仍可浏览公开内容和体验有限的 AI 功能。

#### 已登录状态

- 展示头像和昵称。
- 点击后打开个人菜单：我的资料、设置、退出登录。
- 登录状态异常时显示重新登录提示，不覆盖当前页面内容。

### PC-007 通用操作反馈

| 场景 | 反馈方式 |
| --- | --- |
| 收藏成功 | Toast 或按钮状态变更 |
| 复制成功 | Toast“已复制” |
| 删除操作 | 二次确认窗口 |
| 保存成功 | 页面内提示或 Toast |
| 操作失败 | 说明原因和重试入口 |
| 需要登录 | 登录引导窗口 |

按钮文案必须说明动作，例如“删除会话”，不能只显示“确定”。

### PC-008 空状态、加载和错误状态

所有产品页面都需要覆盖：

1. 首次加载。
2. 正常展示。
3. 没有内容。
4. 内容加载失败。
5. 网络不可用。
6. 用户没有权限。
7. 内容已经下架。
8. 用户重复点击。

## 4. 首页功能

### HOME-001 首页工作区

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 左侧导航“首页” |

#### 页面结构

1. 顶部标题和全局搜索。
2. 精选、日漫、剧场版分类。
3. 主 Banner。
4. 热度排行榜和番剧排期表快捷入口。
5. 热门新番分区。
6. 日漫分区。
7. 完结推荐或其他内容分区。

#### PC 布局

- 主内容区最大宽度建议 1280 px。
- Banner 占据内容区主要宽度，但不超过用户第一屏可阅读范围。
- 热门内容使用 4 至 5 列卡片；窗口变窄时减少列数。
- 内容分区标题和“更多”入口保持同一水平线。

#### 验收标准

- 用户进入首页后可以看到至少一个可操作内容区。
- 某个分区没有内容时隐藏该分区，不留下空标题。
- 首页整体不会出现横向滚动条，除作品横向列表自身外。

### HOME-002 内容分类

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 分类 | 精选、日漫、剧场版 |

#### 操作规则

- 默认进入“精选”。
- 点击分类后只更新内容工作区。
- 当前分类使用青色文字和底部指示线。
- 切换分类时保留顶部搜索和左侧导航。
- 离开首页后返回，优先恢复用户上次浏览的分类。

### HOME-003 Banner 推荐

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 展示内容

- 作品主视觉。
- 作品名称或短文案。
- 类型、状态或更新提示。
- 分页指示。

#### 操作规则

- 支持左右切换和自动轮播。
- 鼠标悬停时暂停自动轮播。
- 点击 Banner 主体进入作品详情。
- 点击分页指示可以切换指定 Banner。
- 图片加载失败显示默认占位，不破坏 Banner 高度。

### HOME-004 快捷入口

首页提供两个高频入口：

#### 热度排行榜

- 进入排行榜页面。
- 默认显示本周榜。
- 支持日榜、周榜和月榜。
- 点击作品进入详情。
- 支持从作品行进入 AI。

#### 番剧排期表

- 进入排期页面。
- 默认定位今天或最近更新日期。
- 支持切换日期。
- 展示更新时间、作品名称和更新状态。
- 时间待定的作品显示“时间待定”。

### HOME-005 热度排行榜

| 项目 | 说明 |

| 优先级 | P0 |

#### 列表信息

- 排名。
- 封面。
- 作品名称。
- 类型标签。
- 热度或趋势。
- 更新状态。
- 查看详情、收藏和问 AI 操作。

#### 状态

- 有数据：按排名展示列表。
- 无数据：展示“暂无榜单数据”。
- 数据更新中：保留上一版榜单并显示更新时间。

### HOME-006 番剧排期表

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 页面结构

- 日期切换栏。
- 当日更新数量。
- 按时间排序的作品列表。
- 作品封面、名称、集数和状态。

#### 操作规则

- 用户可以使用鼠标点击日期或左右切换日期。

- 切换日期只刷新列表区域。
- 完结作品不进入普通更新日程，特别节目除外。

- 横向分区支持滚轮横向滚动和底部拖动条。
- 海报网格支持分页或继续加载。
- 分区顺序保持稳定，除非运营调整。

- 点击主体进入详情。
- 鼠标悬停显示更多操作。

## 5. AI 聊天功能

### AI-001 AI 工作区

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 左侧导航“AI”、作品详情“问 AI” |

#### 默认布局

- 左侧：会话列表，宽度稳定。
- 中间：聊天消息和输入区，占据主要空间。
- 右侧：当前作品或推荐作品，可收起。

#### 布局变化

- 用户收起左侧会话列表时，显示恢复按钮。
- 用户收起右侧上下文区时，中间聊天区扩展。
- 窗口变窄时先收起右侧，再压缩左侧，最后进入单栏模式。
- 输入区始终位于聊天区底部，不被右侧区域遮挡。

### AI-002 AI 空状态

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 中央区域展示

- 标题：`今天想聊哪部番？`
- 副标题：`找番、查剧情、看排期，都可以问我`
- 快捷任务：帮我找番、剧情问答、角色百科、观看顺序。
- 推荐问题。
- 输入框和发送按钮。

#### 右侧区域展示

- 热门提问。
- 今日推荐。
- AI 能做什么的短标签，而不是大段说明。

从作品进入时，标题可以变为“想了解这部番的什么？”，右侧直接展示该作品。

### AI-003 新建会话

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 会话列表顶部“新建会话” |

#### 操作流程

1. 用户点击新建会话。
2. 当前会话已经有内容时，保留在历史列表中。
3. 中间区域切换为空状态。
4. 右侧清除当前作品上下文，除非用户从作品详情再次进入。
5. 用户发送第一条消息后，当前会话显示在历史列表顶部。

#### 验收标准

- 连续点击不会出现多个空会话。
- 新建不会删除旧会话。
- 当前输入草稿不会混入新会话。

### AI-004 快捷任务

| 任务 | 默认问题 |
| --- | --- |
| 帮我找番 | 推荐几部符合我偏好的动漫，并说明理由 |
| 剧情问答 | 我想了解这部作品的剧情和主要人物 |
| 角色百科 | 介绍这部作品中的主要角色和人物关系 |
| 观看顺序 | 这个系列应该按照什么顺序观看 |

#### 规则

- 点击快捷任务后填入输入框，不直接发送。
- 用户可以修改模板内容。
- 从作品详情进入时，问题自动带上当前作品名称。
- 快捷任务不绕过剧透设置和内容规则。

### AI-005 输入框

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 输入规则

- 支持多行文本。
- 最多 2,000 个字符。
- 空白内容不能发送。
- Enter 默认发送，Shift + Enter 换行。
- 可以在设置中改为 Enter 换行。
- 输入框最多展示 5 行，超过后在输入框内部滚动。
- 支持复制、粘贴、全选和撤销。

#### 草稿规则

- 用户切换页面时保留当前草稿。
- 每个会话的草稿独立保存。
- 消息发送成功后清空草稿。
- 退出客户端后再次打开，提示是否恢复未发送草稿。

### AI-006 发送问题

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 操作流程

1. 用户点击发送或按 Enter。
2. 页面立即展示用户消息。
3. 输入框清空并进入等待回答状态。
4. AI 消息区域展示生成中的状态。
5. 回答完成后展示完整内容和后续操作。

#### 防重复规则

- 发送后按钮暂时不可重复点击。
- 用户消息只展示一次。
- 网络异常时保留问题，提示用户重试。
- 重试不会在消息列表中产生第二条相同问题。

### AI-007 消息阅读区

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

- 用户消息右侧对齐，AI 消息左侧对齐。
- 消息区域支持滚轮、拖动滚动条和回到底部。
- 用户位于底部时，新内容自动滚动。
- 用户正在查看历史内容时，不强制跳到底部；显示“有新内容”。
- 长回答支持标题、列表、引用、折叠段落和作品卡片。
- 代码、长链接和表格不会撑破内容区域。

### AI-008 回答过程

| 状态 | 页面表现 |
| --- | --- |
| 准备中 | AI 头像和轻量加载状态 |
| 正在回答 | 文字逐步出现，显示停止按钮 |
| 已完成 | 显示复制、反馈和推荐操作 |
| 已停止 | 显示已生成内容和继续提问 |
| 回答失败 | 显示失败原因和重试 |
| 暂不可回答 | 显示友好说明和问题改写建议 |

### AI-009 停止回答

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 回答生成期间的“停止”按钮 |

#### 操作规则

1. 用户点击停止。
2. 页面停止继续展示新文字。
3. 已出现的回答内容保留。
4. 状态变为“已停止”。
5. 输入框恢复可用。

重复点击停止不产生额外结果，回答已完成后不显示停止按钮。

### AI-010 重新生成回答

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 可用状态 | 回答失败或用户主动停止 |

- 使用原问题重新生成，不增加第二条用户问题。
- 重新生成前保留原回答或失败提示，避免页面突然跳动。
- 连续失败时提示稍后再试。
- 用户可以继续输入新问题，不必等待重试完成。

### AI-011 AI 回答内容

#### 产品要求

- 回答优先直接解决问题，再补充说明。
- 推荐问题给出明确理由，不只列作品名称。
- 不确定的信息明确标注不确定。
- 作品事实与 AI 观点使用不同的视觉层级。
- 重要剧情按剧透模式处理。
- 回答末尾可以给出 2 至 3 个后续问题建议。

### AI-012 剧透模式

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |
| 默认值 | 避免剧透 |

#### 模式

- 避免剧透。
- 允许剧透。

#### 规则

- 设置位于聊天区顶部或右侧作品上下文区。
- 切换后影响后续问题，不修改历史回答。
- 避免剧透时不主动展示结局、死亡、关键身份和反转。
- 允许剧透时，回答开头显示“以下内容可能包含剧透”。
- 从作品详情进入时继承用户最近一次偏好。

### AI-013 推荐作品卡片

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

#### 卡片内容

- 封面。
- 作品名称。
- 类型标签。
- 集数或完结状态。
- 推荐理由。
- 查看详情、收藏、继续追问。

#### 交互规则

- 卡片主体点击进入作品详情。
- 收藏按钮只改变该作品状态，不改变当前对话。
- 点击“继续追问”在输入框填入与该作品相关的问题模板。
- 推荐数量默认 3 至 5 部。
- 卡片排列支持横向比较，不遮挡聊天内容。

### AI-014 右侧作品上下文区

#### 当前作品状态

- 显示封面、标题、类型和状态。
- 显示进入 AI 的来源。
- 显示剧透模式。
- 提供查看详情和清除上下文。

#### 推荐作品状态

- 显示当前回答涉及的推荐作品。
- 用户可以点击作品切换查看对象。
- 支持收起和展开。
- 清除上下文不会删除已经生成的回答。

### AI-015 从 AI 查看作品

- 点击作品卡片后打开作品详情。
- 返回 AI 后恢复原会话、滚动位置和右侧面板状态。
- 作品详情中的“问 AI”默认回到来源会话。
- 如果用户已经删除来源会话，则创建新的空会话。

### AI-016 复制回答

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |

- 复制整条回答或选中部分文字。
- 复制内容保持段落和列表的可读性。
- 不复制界面按钮文字、内部提示或隐藏内容。
- 成功后显示“已复制”。

### AI-017 回答反馈

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |

#### 反馈类型

- 有帮助。
- 没帮助。
- 事实错误。
- 剧透。
- 推荐不合适。
- 其他。

#### 操作规则

- 点踩时可以选择原因。
- 选择“其他”时可补充 200 字以内说明。
- 提交后显示已反馈状态。
- 同一条回答只保留一个最终反馈结果。

### AI-018 会话列表

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |
| 位置 | AI 页面左侧 |

#### 列表内容

- 新建会话按钮。
- 会话标题。
- 最近消息摘要。
- 最近更新时间。
- 更多操作按钮。

#### 规则

- 最近使用的会话排在最前。
- 当前会话高亮。
- 会话标题过长时截断，悬停显示完整标题。
- 会话列表为空时展示“还没有聊天记录”。
- 支持滚动查看更早会话。

### AI-019 打开历史会话

1. 用户点击左侧会话。
2. 中央区域展示消息内容。
3. 右侧恢复当前作品或推荐作品上下文。
4. 页面滚动到最近消息。
5. 输入框恢复该会话草稿。
6. 用户可以继续提问。

如果会话已经删除、不可用或内容不完整，展示说明并允许返回会话列表。

### AI-020 会话标题

#### 默认标题

- 使用首个问题生成摘要。
- 最多显示 20 个有效字符。
- 不展示敏感或违规词汇。

#### 手动重命名

- 通过会话更多菜单进入。
- 最多 50 个字符。
- 不能为空。
- 保存后立即更新列表。
- 取消时恢复原标题。

### AI-021 归档会话

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |

- 归档后从默认最近列表隐藏。
- 可以在“已归档”中查看和恢复。
- 归档不会删除消息。
- 当前会话归档后回到空状态。

### AI-022 删除会话

| 项目 | 说明 |
| --- | --- |
| 优先级 | P0 |

- 删除前展示确认窗口。
- 确认窗口说明会话内容将不可在客户端恢复。
- 删除当前会话后回到 AI 空状态。
- 删除其他会话后只更新左侧列表。
- 删除失败时保留会话并提供重试。

### AI-023 会话搜索

| 项目 | 说明 |
| --- | --- |
| 优先级 | P1 |

- 在左侧会话列表顶部提供搜索入口。
- 支持按会话标题和首条问题搜索。
- 无结果时显示“没有找到相关会话”。
- 清空关键词后恢复最近会话列表。

### AI-024 匿名体验和登录引导

#### 未登录用户

- 可以浏览公开作品。
- 可以体验有限次数的 AI 对话。
- 会话优先保存在当前设备。
- 收藏、跨设备历史和超过体验次数时提示登录。

#### 登录引导规则

- 说明登录能获得什么，不使用强制打断式弹窗。
- 登录返回后恢复用户正在输入的问题。
- 用户取消登录后仍可以继续浏览公开内容。

### AI-025 使用限制提示

- 体验次数用尽时展示剩余状态和恢复时间。
- 不把“系统繁忙”和“用户额度用尽”混为一谈。
- 限制提示提供登录或稍后再试入口。
- 用户重试失败不会无限弹窗。

### AI-026 继续追问

- 同一会话中可以连续提问。
- 用户不需要重复输入作品名称。
- 当较早内容不再参与当前讨论时，产品可以提示“已根据最近内容继续回答”。
- 用户切换到新会话后，不继承旧会话的讨论内容。

### AI-027 作品比较

| 项目 | 说明 |
| --- | --- |
| 优先级 | P2 |

- 用户可以将 2 至 3 部推荐作品加入比较区。
- 比较维度包括题材、节奏、集数、完结状态和适合人群。
- 比较结果支持打开详情和收藏。
- 超过 3 部时提示先移除作品。

## 7. 桌宠功能

桌宠详细需求见 [桌宠产品需求](./desktop-companion-requirements.md)。本节只维护客户端功能清单中的模块入口和优先级，避免与专项文档重复定义。

### PET-001 桌宠显示与角色状态

- 优先级：P0。
- 显示三叶角色和晚霞流星场景。
- 支持待机、关注、对话、睡眠和离线状态。
- 支持减少动效和关闭动态效果。

### PET-002 桌宠交互与客户端入口

- 优先级：P0。
- 支持单击、双击、右键、拖动、停靠、隐藏、恢复和退出。
- 支持打开客户端首页、进入 AI 和恢复最近内容。
- 未登录、断网、超时和客户端未启动时展示明确结果。

### PET-003 桌宠设置与提醒

- 优先级：P0/P1。
- P0 支持大小、透明度、动态效果、气泡、开机启动和恢复默认。
- P1 支持收藏更新、排期提醒、安静时段、提醒合并和快捷键唤醒。
- 主动提醒默认遵循用户选择，不在安静时段打扰。

### PET-004 桌宠边界

- 桌宠不复制完整动漫内容、收藏、会话历史和管理能力。
- 桌宠不持有模型密钥、后台凭证或超出用户权限的私密数据。
- 桌宠不默认启用麦克风、摄像头、持续录音或高打扰通知。
- 角色、图片和动画素材正式发布前必须通过授权门禁。

## 8. 账户和内容规则

### ACCOUNT-001 公开内容和登录内容

| 功能 | 未登录 | 已登录 |
| --- | --- | --- |
| 浏览首页 | 可用 | 可用 |
| 搜索作品 | 可用 | 可用 |
| 查看详情 | 可用 | 可用 |
| AI 体验 | 有限体验 | 完整体验 |
| 收藏 | 引导登录 | 可用 |
| 云端历史 | 不可用 | 可用 |
| 意见反馈 | 可用 | 可用 |

### ACCOUNT-002 作品内容规则

- 作品名称、封面、类型和状态保持统一展示。
- 作品信息不完整时展示已有内容，不填充虚构信息。
- 下架作品不能显示失效的观看或外部跳转按钮。
- 作品图片需要有明确使用来源。

### ACCOUNT-003 AI 内容规则

- AI 回答是辅助内容，不代替平台的作品信息展示。
- AI 推荐必须给出推荐理由。
- AI 不确定时要明确说明。
- AI 不能承诺未确认的播放、下载或资源链接。
- 用户可以反馈 AI 的事实错误和不合适回答。

### ACCOUNT-004 删除和恢复规则

- 删除会话前必须确认。
- 删除后客户端不再展示该会话。
- 归档和删除是不同操作，归档可以恢复，删除默认不可恢复。
- 清理本地记录不等同于删除云端数据，产品提示需要区分。

```text
打开客户端
  -> 首页精选
```

```text
进入 AI
```

## 10. 页面验收标准

### 9.1 PC 窗口和布局

- 1440 x 900 窗口下导航、顶部工具栏和主内容区层级清晰。
- 窗口宽度缩小到 1100 px 时仍能搜索、查看作品和发送问题。
- 左侧导航折叠后，图标仍能识别并提供文字提示。
- 首页作品卡片可以在 3 至 5 列之间自然调整。
- AI 右侧区域收起和展开不会遮挡输入框。
- 所有弹窗和下拉菜单在窗口边缘内完整显示。

### 9.2 首页

- 用户可以切换精选、日漫和剧场版。
- Banner、排行榜、排期和作品卡片可以进入详情。
- 搜索有结果、无结果和失败都有清晰状态。
- 图片失败时保留卡片比例和操作入口。
- 首页滚动后返回顶部工具栏和导航仍然可用。

### 9.3 AI 功能规则

- 用户可以从空状态发起第一条问题。
- 用户可以从作品详情进入带当前作品的 AI 页面。
- 生成期间可以停止，停止后保留已经生成的内容。
- 失败时可以重试，不增加重复问题。
- 推荐作品可以查看详情、收藏和继续追问。
- 会话可以打开、重命名、归档和删除。
- 默认避免剧透，允许剧透时有明确提示。

### 9.4 我的

- 未登录状态和已登录状态信息不同但页面结构稳定。
- 收藏、浏览记录和 AI 历史都有空状态。
- 删除、退出、清理和注销都有确认和结果反馈。
- 设置项变更后重新打开客户端仍保持用户选择。

## 12. 已冻结产品决策

| 决策项 | MVP 规则 |
| --- | --- |
| 客户端形态 | PC Web，优先支持 Windows；Electron 延后 |
| AI 上下文面板 | 从作品详情进入时展开；直接进入 AI 时收起 |
| 最近访问 | 固定放在顶部工具栏 |
| 键盘快捷键 | 只提供固定常用快捷键；不提供自定义快捷键编辑器 |
| 登录边界 | 无需登录即可浏览公开内容；个人数据和云端 AI 历史需要登录 |
| AI 额度 | 初始默认匿名用户每日 5 次、登录用户每日 30 次；生产前可配置 |
| 外部链接 | 只允许审核通过的合法链接；不提供未授权的播放、下载或资源聚合 |
| 深色主题 | P1 |
| 作品对比 | P1 |
| 桌宠范围 | 桌宠作为 `sanye_anime` 的 P1 附属形态，Windows 优先，不阻塞核心 PC Web MVP |
| 桌宠默认打扰 | 开机启动和主动提醒遵循用户选择，首版不默认开启高打扰行为 |
