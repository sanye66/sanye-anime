# sanye_anime 视觉设计系统

## 设计定位

所有平台统一采用“黄昏星轨”视觉方向，借鉴《你的名字。》中黄昏天空、彗星、星光、神社纸垂和结绳等意象，形成属于 `sanye_anime` 的原创界面语言。界面不直接使用角色立绘、电影海报或受版权保护的场景素材。

## 核心色彩

| 语义 | 颜色 | 用途 |
| --- | --- | --- |
| 黄昏蓝 | `#1d385d` | 页面主背景、导航、信息工作区 |
| 深夜蓝 | `#0a1628` | 暗色主题底色、管理平台底色 |
| 彗星珊瑚 | `#df7b69` | 主行动、重点内容、品牌标记 |
| 星光金 | `#f0c66c` | 评分、状态、焦点、辅助行动 |
| 结绳红 | `#a7464f` | 警示、法律信息、重要状态和分割线 |
| 晨雾冰蓝 | `#9dcbd8` | 次级内容、头像、数据辅助色 |
| 星尘白 | `#eef3c7` | 暗色主题高亮文字和装饰星点 |

## 三个平台的表达

### sanye_anime 客户端

- 以深色观影工作台为默认状态，突出长时间浏览、作品详情和 AI 对话。
- 使用彗星珊瑚作为主行动色，星光金用于评分、聚焦和完成状态。
- 卡片使用轻微的“结绳”非对称圆角，表达故事之间的连接感。
- 页面装饰使用星点、椭圆轨道和低对比度天空渐变，不能影响内容阅读。

### official 官网

- 使用晨曦纸张感的亮色默认状态，保持公开信息的阅读舒适度。
- 通过黄昏蓝大色块、珊瑚色视觉区域和彗星轨迹建立品牌记忆。
- 页面留白大于客户端，标题可以使用衬线字体表达叙事感。
- 法律、版权和公开信息页面保持克制，不使用强装饰覆盖正文。

### 管理平台

- 使用深色星图观测台作为默认状态，适合高密度运营信息查看。
- 保留表格、指标和任务状态的清晰层级，不使用官网式大面积留白。
- 珊瑚色只用于主要行动和重点异常，星光金用于关注状态，避免全屏高饱和。
- 亮色模式切换为晨曦纸张背景，但导航、指标和表格层级保持一致。

## 交互约定

- 三个平台使用相同的亮色/暗色切换语义，并通过 `localStorage` 保留用户选择。
- 主题切换按钮使用太阳/月亮符号，必须提供中文 `aria-label` 和 `title`。
- 动效以主题切换、悬停、轨道装饰为主，支持 `prefers-reduced-motion`。
- 不使用渐变球、无意义发光装饰或与信息无关的大幅插画。
