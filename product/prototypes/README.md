# sanye_anime 页面原型

这是基于当前产品功能范围制作的可交互静态页面原型，用于确认页面结构、信息层级、核心操作和状态表现。

## 原型入口

- [客户端原型](./client.html)：直接双击打开，默认进入 `sanye_anime` 客户端。
- [官网原型](./official.html)：直接双击打开，默认进入 `official` 官网。
- [兼容入口](./index.html)：保留原入口，默认进入客户端。

三个 HTML 都不依赖前端构建工具，不需要安装依赖，也不需要启动本地服务。请保留 `prototype.css` 和 `prototype.js` 与 HTML 文件处于同一目录。

## 原型范围

### sanye_anime 客户端

- 首页：顶部搜索、三张精选内容轮播、最近更新、热门动漫、番剧排期和 AI 入口。
- 番剧仓库：关键词搜索、类型、状态、年份筛选、无结果提示和作品详情入口。
- 一周排期：星期一至星期日的更新时间总览和作品详情入口。
- 作品详情：作品信息、收藏、进入 AI、角色和观看顺序。
- AI 对话：会话列表、快捷问题、作品上下文、剧透模式、发送问题和推荐卡片。
- 我的：个人资料、收藏、浏览记录、会话历史和设置入口。

### official 官网

- 公开首页：产品定位、功能介绍、公开作品和进入客户端。
- 产品介绍：客户端、AI 助手和内容发现能力。
- 下载页面：客户端版本状态、直接体验入口和安装包状态提示。
- 法律信息：隐私政策、使用条款和版权说明。

## 原型操作

- 顶部切换器可以在 `sanye_anime` 客户端和 `official` 官网之间切换。
- 客户端首页可以切换三张精选内容，并从搜索栏进入番剧仓库。
- 番剧仓库可以按关键词、类型、状态和年份筛选。
- 左侧导航可以切换同一产品中的页面。
- 客户端首页的作品卡片可以进入作品详情。
- 作品详情可以切换收藏状态并进入 AI 对话。
- AI 页面可以发送问题、切换会话和切换剧透模式。
- 官网可以进入下载页、产品介绍、法律信息和客户端静态原型。

## 设计说明

客户端和官网统一使用蓝紫、玫粉、珊瑚和暖金晚霞背景，以及具有多色光晕的流星轨迹。客户端保持工作区式信息布局，官网保持更开放的公开阅读布局；两者都支持亮色和暗色主题。
