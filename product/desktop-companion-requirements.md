## 1. 产品定位

桌宠是 `sanye_anime` 的桌面陪伴入口。它以宫水三叶为核心角色形象，显示在用户桌面边缘，用轻量的动作、互动按钮和气泡让用户可以快速回到动漫内容与 AI 动漫助手。首版只绘制透明窗口中的角色和互动控件，不绘制晚霞、流星、远山等场景背景。

桌宠不是第二个完整客户端，也不是独立的内容管理平台。它的主要价值是：

1. 让用户启动 `sanye_anime` 客户端时同步看到三叶桌宠。
2. 让用户可以快速打开客户端、进入 AI 或恢复上次内容。
3. 用低打扰的角色反馈增加长期使用的情感连接。
4. 在离线或服务不可用时仍能保持基础陪伴，不制造错误承诺。

## 2. 产品目标与非目标

### 2.1 首版目标

- 桌宠可以在 Windows 桌面显示、移动、隐藏和恢复。
- 用户可以通过点击、双击和右键菜单完成主要操作。
- 桌宠具有待机、关注、对话、提醒、睡眠和离线等可理解状态。
- 用户可以从桌宠快速进入首页、AI、最近内容和设置。
- 用户可以控制开机启动、显示位置、大小、透明度、提醒和安静时段。
- 桌宠默认不主动打断用户，不自动播放声音，不强制推送消息。

### 2.2 首版不包含

- 复杂的养成、等级、道具、积分和商城。
- 语音通话、连续语音监听和摄像头能力。
- 多角色同时养成和角色自由编辑器。
- 需要高性能显卡的重型三维场景。
- 没有用户明确授权的开机启动、通知或后台行为。
- 用桌宠替代完整客户端的动漫浏览、收藏和历史管理页面。

## 3. 目标用户与使用场景

| 用户 | 场景 | 期望结果 |
| --- | --- | --- |
| 长时间使用客户端的用户 | 工作或学习时希望保留一点角色陪伴 | 桌宠安静待机，不遮挡窗口 |
| AI 使用者 | 突然想到动漫问题 | 点击桌宠后快速进入 AI |
| 追番用户 | 想知道最近收藏内容是否有更新 | 在允许提醒时看到轻量提醒 |
| 新用户 | 第一次接触 `sanye_anime` | 从桌宠了解并打开客户端 |
| 低频用户 | 很久没有打开客户端 | 桌宠通过温和状态引导恢复使用，不制造压力 |

## 4. 产品形态与入口

### 4.1 桌宠与客户端关系

```text
Windows 桌面
  |
  v
三叶桌宠
  ├── 快速打开客户端首页
  ├── 快速进入 AI 动漫助手
  ├── 恢复最近作品或会话
  ├── 展示允许的提醒
  └── 打开桌宠设置
          |
          v
    sanye_anime PC 客户端
```

桌宠负责快速入口和陪伴表现，完整内容、账户、收藏、AI 历史和反馈仍由客户端负责。桌宠由客户端开发启动器统一拉起；重复执行启动命令时复用已有服务和单实例窗口，不持续重复打开新窗口，也不默认作为独立常驻程序自动启动。

### 4.2 首次进入

用户通过客户端开发启动器打开 `sanye_anime` 时，桌宠随客户端自动拉起；首次进入桌宠需要展示简短欢迎信息：

- 说明这是三叶桌面伴侣。
- 说明桌宠可以移动、隐藏和从菜单关闭。
- 让用户选择是否开机启动。
- 让用户选择是否接收提醒。
- 让用户知道可以随时在设置中修改。

首次进入不得默认开启高打扰行为。

## 5. 功能需求

### PET-001 桌宠显示

| 项目 | 内容 |
| --- | --- |
| 优先级 | P0 |
| 入口 | 打开桌宠或从客户端启动桌宠 |
| 说明 | 在透明窗口中只显示三叶角色和互动按钮，保持轻量、清晰和可识别 |
| 默认表现 | 位于桌面右下区域，避开系统主要操作区域 |
| 成功状态 | 角色完整显示，边缘清晰，桌宠不遮挡用户主要窗口 |
| 异常状态 | 素材加载失败时显示简化占位形象和恢复入口 |

验收要求：

- 桌宠首次显示时不出现白屏、黑屏或闪烁的大块背景，透明区域不绘制场景。
- 桌宠可以在不同桌面缩放比例下保持可辨识。
- 角色主体使用三叶的短发、红色发绳、蓝色和服和侧背包等识别元素。

### PET-002 待机与角色动作

| 项目 | 内容 |
| --- | --- |
| 优先级 | P0 |
| 说明 | 在没有用户操作时保持安静的周期性动作 |
| 动作示例 | 轻微呼吸、衣摆变化、点头、挥手或关注用户 |
| 触发规则 | 不同动作之间自然切换，不连续快速跳变 |
| 用户控制 | 可以在设置中关闭动态效果 |

动作设计要求：

- 动作必须服务于陪伴氛围，不使用持续高频抖动。
- 用户正在拖动或操作桌宠时，待机动作暂停。
- 开启减少动效后保留静态角色和必要状态变化。

### PET-003 点击交互

| 操作 | 行为 |
| --- | --- |
| 单击角色 | 展开简短气泡或快捷操作面板 |
| 双击角色 | 打开 `sanye_anime` 客户端首页 |
| 点击气泡操作 | 执行对应的客户端入口 |
| 点击空白处 | 收起气泡和快捷操作面板 |

快捷操作至少包含：

- 打开客户端。
- 问三叶一个问题。
- 继续最近内容。
- 查看桌宠设置。

### PET-004 拖动、停靠与隐藏

| 操作 | 行为 |
| --- | --- |
| 拖动角色 | 桌宠跟随鼠标移动 |
| 拖到屏幕边缘 | 可以停靠在左、右或下边缘 |
| 双击边缘桌宠 | 在可恢复位置重新显示 |
| 选择隐藏 | 桌宠暂时退出桌面显示 |
| 选择退出 | 关闭桌宠进程或桌面伴侣入口 |

规则：

- 拖动结束后保存最近位置。
- 桌宠不得被拖到无法恢复的位置。
- 隐藏不等于退出；隐藏后必须有明确恢复方式。
- 退出后不得在用户未主动启动时偷偷恢复显示。

### PET-005 角色气泡与快速问答

| 项目 | 内容 |
| --- | --- |
| 优先级 | P0 |
| 说明 | 允许用户从桌宠发起轻量问题，并把完整问答交给客户端 |
| 首版范围 | 输入问题、展示请求中、展示简短结果或跳转客户端查看完整结果 |
| 默认行为 | 桌宠不自行编造动漫事实；无法确定时引导进入客户端 |
| 登录要求 | 需要账户能力时，引导用户进入客户端登录 |

示例：

```text
用户点击桌宠
  -> 选择“问三叶一个问题”
  -> 输入“最近有什么轻松的恋爱番？”
  -> 桌宠显示等待状态
  -> 返回简短结果
  -> 用户选择“在客户端继续”
```

首版不在桌宠中复制完整聊天历史、作品上下文面板和复杂推荐比较。

### PET-006 最近内容恢复

| 项目 | 内容 |
| --- | --- |
| 优先级 | P0 |
| 说明 | 提供返回最近作品、最近会话或上次离开位置的入口 |
| 无记录状态 | 显示“还没有最近内容”，引导打开首页 |
| 内容失效状态 | 作品下架或会话不可用时给出说明，不跳转到空白页面 |

桌宠只展示用户有权访问的最近内容，不在桌面暴露私人标题、问题或敏感信息。

### PET-007 提醒与安静时段

| 项目 | 内容 |
| --- | --- |
| 优先级 | P1 |
| 默认状态 | 关闭主动提醒，用户开启后才生效 |
| 提醒内容 | 收藏作品更新、排期变化、客户端任务结果 |
| 表现形式 | 轻微动作、短暂气泡或系统通知，三者不同时强制出现 |
| 安静时段 | 用户可设置开始时间和结束时间 |
| 频率控制 | 同类提醒合并，避免连续打扰 |

以下情况不得主动打扰：

- 用户处于安静时段。
- 用户已连续关闭同类提醒。
- 网络或内容状态无法确认。
- 提醒内容未通过产品发布规则。

### PET-008 桌宠设置

设置至少包含：

- 开机启动。
- 显示位置和边缘停靠。
- 角色大小。
- 透明度。
- 动态效果开关。
- 提醒开关。
- 安静时段。
- 是否显示气泡文字。
- 快捷键开关。
- 恢复默认设置。
- 关于桌宠和退出桌宠。

设置修改后应立即生效，并在下次打开桌宠时保持。

### PET-009 离线与异常状态

桌宠至少需要展示以下状态：

| 状态 | 用户可见表现 | 可执行操作 |
| --- | --- | --- |
| 在线 | 正常待机和交互 | 打开客户端、提问、查看最近内容 |
| 请求中 | 角色关注输入或显示等待气泡 | 取消或等待 |
| 网络不可用 | 安静提示“暂时无法连接” | 打开客户端、重试、关闭提示 |
| 未登录 | 提示需要进入客户端登录 | 打开登录入口、取消 |
| 内容不可用 | 说明内容已下架或暂不可见 | 返回首页、关闭提示 |
| 素材异常 | 显示简化角色或恢复入口 | 重试、打开设置、退出 |

异常状态不能导致桌宠无限重试、持续弹窗或占满桌面。

## 6. 角色状态设计

```text
隐藏
  -> 待机
  -> 关注
  -> 对话中
  -> 提醒
  -> 睡眠
  -> 离线
  -> 隐藏
```

| 状态 | 进入条件 | 退出条件 |
| --- | --- | --- |
| 待机 | 桌宠显示且没有进行操作 | 用户点击、拖动、提醒、进入安静时段 |
| 关注 | 用户点击或鼠标靠近 | 用户离开或打开操作面板 |
| 对话中 | 用户提交问题 | 返回结果、失败或取消 |
| 提醒 | 有允许展示的更新或任务结果 | 用户查看、关闭或超时 |
| 睡眠 | 长时间无操作或进入安静时段 | 用户点击、快捷键唤醒或退出安静时段 |
| 离线 | 无法获得在线服务 | 网络恢复、用户重试或关闭提示 |
| 隐藏 | 用户选择隐藏 | 用户从客户端或桌面入口恢复 |

状态切换必须有明确表现，但不能用持续闪烁、强声音或大面积弹窗代替状态说明。

## 7. 视觉与角色要求

### 7.1 三叶识别特征

- 短发轮廓。
- 红色发绳。
- 蓝色和服或带和服结构的服装。
- 腰带和侧背包。
- 角色姿态以站立、待机、挥手和关注用户为主，不依赖场景背景表达角色状态。

### 7.2 透明窗口与控件方向

- 窗口必须透明、无边框，不绘制晚霞、流星、远山或其他场景背景。
- 角色本体与互动按钮是首版唯一可见主体；控件应有清晰命中区域和状态反馈。
- 角色和按钮必须与用户桌面保持足够对比度，但不得用大面积底板遮挡桌面。
- 透明区域不拦截未命中的桌面操作，拖动仅作用于角色可拖动区域。

### 7.3 使用边界

- 原型阶段可以使用已确认的参考素材进行角色校准。
- 正式发布前必须确认角色形象、图片、动画和相关素材的使用授权。
- 不直接把参考图片整张作为桌面背景。
- 不在角色旁增加与产品无关的品牌水印、平台标识或营销文字。

```text
  -> 用户查看、关闭或稍后处理
```

## 9. 优先级范围

### P0 首版必须完成

- 桌宠显示和关闭。
- 三叶角色基础视觉。
- 待机、关注、对话、离线状态。
- 单击、双击、右键和拖动。
- 打开客户端、进入 AI、恢复最近内容。
- 基础气泡和错误提示。
- 大小、透明度、动态效果和开机启动设置。
- 隐藏、恢复和退出。

### P1 首轮迭代完成

- 收藏更新提醒。
- 番剧排期提醒。
- 安静时段和提醒合并。
- 快捷键唤醒。
- 更多角色动作和节日主题。
- 桌宠与客户端主题联动。

### P2 后续探索

- 语音问答和语音播报。
- 角色长期记忆和成长体系。
- 多角色切换。
- 桌面小游戏和互动道具。
- 跨设备状态同步。
- 高保真三维角色和复杂场景。

## 10. 产品验收标准

### 10.1 基础可用性

- 用户可以启动、隐藏、恢复和退出桌宠。
- 用户可以拖动桌宠，重启后位置符合预期。
- 桌宠不会遮挡客户端主要操作，也不会阻止用户关闭它。
- 单击、双击、右键和拖动不会互相误触。

### 10.2 角色与视觉

- 首屏可以识别三叶的短发、红色发绳、蓝色和服和侧背包。
- 透明区域不绘制场景背景，角色和互动按钮边缘清晰且不遮挡客户端主要内容。
- 动态效果关闭后仍可正常使用。
- 开启减少动效后不会出现快速闪烁或连续位移。

### 10.3 客户端承接

- 从桌宠进入首页、AI 和最近内容时，目标页面可以正确打开。
- 未登录、网络不可用、内容下架和服务失败时有明确结果。
- 桌宠不展示超出用户权限的私人内容。

### 10.4 打扰控制与隐私

- 开机启动和主动提醒默认遵循用户选择。
- 安静时段内不出现主动提醒。
- 用户可以关闭气泡、动画和通知。
- 桌宠不会在没有授权时使用麦克风、摄像头或持续录音。

### 10.5 稳定性

- 网络断开时桌宠仍能保持基础待机和关闭能力。
- 请求超时后不会无限重试或重复弹窗。
- 素材加载失败时可以恢复或退出，不留下不可关闭窗口。

## 11. 待确认事项

以下事项不阻塞已冻结的产品边界，但在 Windows 发布验收前必须确认：

- Windows 开机启动是否首版提供，默认是否关闭。
- Windows 多屏、系统缩放、锁屏唤醒和位置恢复行为。
- 桌宠人物最终使用静态图、序列帧还是轻量动画资产。
- AI 快速问答是否首版直接打开客户端，还是提供桌宠内的轻量回答。
- 提醒是否依赖客户端已登录状态。
- 正式发布所需的角色与图片素材授权范围。

## 12. 产品结论

桌宠适合作为 `sanye_anime` 的 P1 增量能力。首版应聚焦“透明、可拖动、可互动、可唤起、低打扰”：客户端启动时自动拉起桌宠，桌宠通过按钮进入客户端，不把桌宠做成独立常驻客户端。复杂养成、语音和三维场景能力不应进入首个桌宠版本，以避免桌宠反过来拖慢客户端和 AI 核心产品交付。
