sanye_anime 安装说明
适用版本：0.1.0 Windows 测试版
本包构建：20260921.1（神经补帧版）

【先看这里】
这是给测试用户使用的版本。请只安装你从开发者或其指定发布页面获得的文件。
适用于 Windows 64 位电脑，不适用于手机、Mac 或 Windows ARM 电脑。
不需要另外安装 Java、数据库或其他开发工具。
安装包较大，下载和安装时请耐心等待。搜索、视频播放和部分图片需要联网。

【方法一：一键启动，推荐使用】

第一步：把压缩包解压出来
找到下载的 .zip 文件，右键点击它，选择“全部解压缩”（有的电脑叫“解压到…”）。
解压完成后打开新文件夹。不要直接在压缩软件里双击安装，也不要只拖出其中一个文件。

第二步：双击启动入口
找到“启动三叶动漫.cmd”，双击它。
如果电脑隐藏了文件后缀，你看到的名称可能是“启动三叶动漫”。
它会直接启动当前文件夹中的“三叶动漫.exe”，不需要安装数据库、Java 或其他开发工具。

第三步：打开应用
请保持解压后的整个文件夹完整，不要单独移动“三叶动漫.exe”。
程序会自动使用包内的 Java、PostgreSQL、数据库模板和业务服务。
关闭程序后，下次继续双击“启动三叶动漫.cmd”即可。
第一次打开会准备本机数据，可能比后续启动慢。看到“正在启动本地服务”时请等待。
关闭程序后，下次可以继续使用；收藏和历史保存在这台电脑上。
页面左上角的箭头可以返回上一页。搜索框输入作品名称后，点击“搜索”即可。
播放器中的星形图标是画质增强菜单，默认关闭；电脑较慢时可先选择“性能”。
画质增强不会把普通视频自动变成 120 帧，流畅度还取决于片源、电脑和显示器。
播放中的帧率提升是实时的：控制栏“帧率”菜单选择档位（默认“自动”），边播边生成补间帧，随时可切换或关闭。

【启动没成功怎么办】

找不到“启动三叶动漫”：
请确认下载已经完成，并打开“解压后的文件夹”，不是压缩包内部。

出现黑色窗口后报错，或程序没有打开：
不要反复双击。保留窗口，截取完整错误信息发给开发者。
请同时说明你双击的是哪个文件、Windows 版本，以及是否从压缩包直接运行。
不要发送密码、登录验证码或私人数据。

提示文件缺失：
停止安装。可能是下载不完整，或混用了不同版本的文件。
从开发者指定的位置重新下载整个压缩包，解压到新文件夹，勿混入旧版文件。
不要随意改名、替换证书或安装程序。

提示“已阻止”、Smart App Control 或“由组织管理”：
不要关闭杀毒软件或修改电脑安全设置来强行安装。
截图交给开发者；公司或学校的电脑请联系管理员。
安装证书也不能保证所有电脑都允许运行。

提示需要管理员账户密码：
当前方案只给你的 Windows 账户安装证书，不应要求你提供他人的账户密码。
先取消并联系开发者或电脑管理员。

程序能打开，但视频不能播放：
先检查网络，尝试其他作品。视频来自外部网站，可能暂时不可用。
这不一定是安装失败；请记录作品名称和页面提示发给开发者。

【如何删除应用】
先退出程序，再删除整个解压文件夹即可。收藏和历史数据位于 Windows 用户数据目录中，不会因删除程序文件夹自动删除。

【方法二：直接启动，供熟悉电脑的人协助】
不会使用 PowerShell 的用户请采用方法一。所有命令均在完整解压后的文件夹中执行。

1. 在命令提示符中运行：
启动三叶动漫.cmd
2. 也可以直接运行：
三叶动漫.exe

【随包文件，不要拆开或删除】
