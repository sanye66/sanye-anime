## 写入选择

| 内容 | 写入位置 |
| --- | --- |
| 需求和用户验收 | `product/` 唯一事实源 |
| 工程设计、环境和测试 | `docs/` 唯一事实源 |
| 经过确认的当前规则摘要 | `views/`、`design/` |
| 决策、缺陷和执行事件 | `ledger/` |
| 读取、冲突和提交规则 | `policy/` |
| 当前执行状态 | `plan/`、`development-plan/` |

不要为了让索引看起来完整而复制尚未验证的内容。每一条新视图至少保留一个源码、测试或唯一事实源链接。
