# AiCoding 文档编写策略

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v0.1 |
| 文档状态 | 基线 |
| 更新时间 | 2026-08-26 |

- 正文、标题、表格说明和 README 使用中文；代码标识符、命令、路径和技术名称保持原文。
- 正式文档头部必须有版本、状态、更新时间和关联来源。
- 单个 Markdown 文件超过 20 KB 时拆分为主题视图；超过 50 KB 时必须按逻辑块读取。
- “已完成”“已验证”“已通过”必须附命令、日志、测试报告或截图证据。
- 计划、当前事实、历史证据和评审记录不得混写。
- 相对链接必须指向仓库内存在的文件或目录。
