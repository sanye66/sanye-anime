## 目录约定

```text
contracts/
├── openapi/       # 机器可读 OpenAPI
├── examples/      # 请求和响应示例
└── metadata/      # 版本、来源和 AI/MCP 扩展元数据
```

OpenAPI 只描述当前源码已确认的接口；管理平台内部 RuoYi 通用接口不在首版公共契约中重复展开。生成或修改契约后，必须同步 `docs/api-contract.md`、客户端调用和测试证据。
