# sanye_anime 基础概念

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v0.1 |
| 文档状态 | 基线 |
| 更新时间 | 2026-08-26 |

| 概念 | 定义 |
| --- | --- |
| `sanye_anime` | 面向动漫发现、观看和 AI 助手的客户端产品 |
| `official` | 官网产品名称，技术实现归入 `sanye_client` |
| 管理平台 | RuoYi 内部运营和审计入口，技术实现为 `sanye_admin` + `sanye_admin_server` |
| 已发布作品 | 通过管理端审核并允许客户端、官网读取的动漫内容 |
| AI 会话 | 用户与动漫助手之间可恢复、可重命名、可归档的对话容器 |
| 外部候选 | 从允许的公开来源读取、尚未导入本地目录的元数据 |
| 预览 | 在站内播放器中只读播放外部候选，不等同于导入或发布 |
| 待环境 | 代码已准备，但缺少外部账号、额度、授权或正式环境证据 |
