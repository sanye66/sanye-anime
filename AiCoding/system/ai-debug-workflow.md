## 调试顺序

1. 复现并记录请求、页面状态、响应状态和关联 ID。
2. 先检查网关、服务端统一错误和权限边界，再检查页面展示。
3. AI 请求检查 provider、模型、超时、额度和 SSE 事件；禁止把失败响应当成模型成功。
4. 媒体请求检查来源白名单、超时、HTML 解析、集数上限和播放器资源销毁。
5. 修复后运行最小单测，再运行对应的 typecheck/build/E2E。
6. 将结果写入唯一事实源或 Ledger，并登记外部阻塞。

## 证据格式

```text
时间：YYYY-MM-DD HH:mm（Asia/Shanghai）
入口：命令或 URL
输入：脱敏后的参数
结果：成功、失败或 blocked-external
证据：日志、测试报告、截图或响应摘要
```

真实 API 密钥、Cookie、个人数据和生产数据永远不进入调试记录。
