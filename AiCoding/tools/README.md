后续工具可以提供相对路径清单、SHA-256 manifest、Markdown 链接扫描、文档大小统计和敏感信息检查。工具应使用当前基线 Node.js 26.5.0 或 PowerShell，不能删除、重写或清理用户工作区。当前项目工具链以 [版本基线](../../docs/version-baseline.md) 为准。
